Automations and scripting

Every automation is a trigger, some conditions and actions. Build it in the visual editor, then switch to YAML whenever you want full control. Example: heat the kitchen floor zone at 5am, but only if it is cold outside.

triggers:
  - trigger: time
    at: "05:00:00"
conditions:
  - condition: numeric_state
    entity_id: sensor.outdoor_temperature
    below: 8
actions:
  - action: climate.set_temperature
    target:
      entity_id: climate.kitchen_floor
    data:
      temperature: 21
  • Underfloor heating is slow, so a better version starts earlier the colder it is, using a template that calculates the start time.
  • Beyond the visual editor: YAML with templates, Node-RED for visual flows, and Pyscript for Python.
